Bundled Libraries
=================

Feature libraries bundled with and maintained within the LifterLMS core plugin:

+ `banner-notifications`: Admin banner notifications.
+ `lifterlms-blocks`: WordPress Editor (Gutenberg) blocks.
+ `lifterlms-cli`: WP-CLI commands (`wp llms ...`).
+ `lifterlms-helper`: Update, install, and beta test LifterLMS add-ons.
+ `lifterlms-rest`: The LifterLMS REST API.

These were formerly developed in separate repositories and installed via Composer. They are now part of this repository and are released with LifterLMS core. Changes to these libraries follow the same contribution workflow as the rest of the core plugin, including changelog entries in `.changelogs/`.

They are not installable as standalone plugins.
